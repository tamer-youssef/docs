### Track your inbound order

<Alert type="warning">
  Skip this step if you are a **delivery-only merchant**.
</Alert>

<Card>
  **Usual inbound order statuses:**

  - Pending: Request created, waiting for confirmation
  - Scheduled: Pickup arranged
  - In Transit: Shipment on its way
  - Received: Inventory checked in
  - Completed: Process finished
</Card>

## Guide 2: Deliver your first order

### Create your first order

<Card>
  For a smooth delivery experience, please ensure your orders include:

  - Customer’s **name** and **phone number**
  - Customer’s **full address** (country, city, area, street name, building number)
  - The **amount to be collected** (including shipping) in the _Amount To Be Collected_ field
</Card>

<Alert type="tip">
  If your customer wants to pay via **3rd party methods** (InstaPay, card, etc.), set the *Amount To Be Collected* to **0**.
</Alert>

Resources:

- 🎥 [VIDEO] Tutorial available

**Actions:**

- Opens connecting website tutorial in PDF (already exists) in a new tab
- Takes user to Orders page, guided tooltip on **Add Order** button

### Track your customer’s order status

<Card>
  **Standard order status flow:**

  - Created: Order added to the system
  - Out for Pickup: Courier on the way
  - Picked Up: Package collected
  - In Transit: Package moving to destination
  - Out for Delivery: Courier en route to customer
  - Delivered: Package successfully delivered
  - Failed Delivery: Attempt unsuccessful
</Card>

**Actions:**

- Opens **Orders** page
