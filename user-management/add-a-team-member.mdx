title: "Invite my team"
description: "Add your team members to grant access to specific features on the portal."
---

Inviting your team is recommended if you've got multiple team members handling your operations.

**Do not** share your password with them. Instead, use the User Management feature to manage which pages they can view and which actions they can perform on each one.

## Add a team member

1. Go to the User Management page and click on "Add New User"
2. Fill in their email and password, they'll use this to log in to your portal
3. Click on "Set Permission" to choose the actions you'd like your new user to perform
   1. **View: **user can only view the page.
   2. **Create:** user can create new objects (e.g. add a new product)
   3. **Edit:** user can edit existing objects (e.g. modify an order)
   4. **Export:** user can download data from the portal (e.g. export invoice CSV sheet)
   5. **Import/Bulk: **user can import data from integrations (e.g. import products from Shopify) or upload bulk sheets (e.g. create orders in bulk)
4. Click "Save Data" to confirm your choices and add the user

<Tip>
  Create a role to add to new users so you don't have to remember your choices every time
</Tip>
